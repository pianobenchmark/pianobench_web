# PianoBench

PianoBench is a project evaluating generated piano-video examples and their audio, visual, and audio-visual scores.

The current index.html page presents:

- 50 prompt IDs across five task levels;
- seven evaluated systems;
- level-specific video examples in the Video and score details carousel; and
- sampled frames for the first prompt level.

Open [index.html](index.html) directly in a browser. The page uses only the media files stored in `data/videos/` and `frames_1a/` that it references.

The benchmark levels are:

1. Single notes
2. Ascending sequences
3. Descending sequences
4. Repeated notes
5. Chords

The page is anonymous.
